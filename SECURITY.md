# Security policy

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/lzh9173/roleharbour/security/advisories/new), not in a public issue. Include the affected version, steps to reproduce and the impact you expect.

You should receive a reply within a week. Fixes are released as a new version on GitHub Releases and the Chrome Web Store.

## Supported versions

Only the latest release receives security fixes.

## Scope

In scope: the extension (content script, service worker, settings page), its handling of SEEK pages and the employer-list download, and the promotional site.

Out of scope: SEEK, the NZAEI dataset service and Chrome itself. Vulnerabilities in development-only dependencies that never ship in the extension package are tracked through Dependabot.
